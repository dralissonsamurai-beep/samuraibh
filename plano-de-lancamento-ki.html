O que falta

As fases abaixo mostram exatamente o que ainda precisa acontecer pra Ki estar pronta pra vender de verdade.

1

Configurar o recebimento de pagamentos

Depende do Dr. Alisson

Criar o Plano Basic no Mercado Pago

Ferramentas de venda → Assinaturas → Criar plano. Nome: "Plano Basic". Valor: R$ 39,00. Frequência: Mensal.

Salvar o link gerado na pasta "Fase 1"

Criar o Plano Business no Mercado Pago

Mesmo caminho. Nome: "Plano Business". Valor: R$ 79,00. Frequência: Mensal.

Salvar o link gerado na pasta "Fase 1"

Criar o link de Suporte Técnico

Ferramentas de venda → Link de pagamento (não é assinatura, é avulso). Nome: "Suporte Técnico". Valor: R$ 149,00.

Salvar o link gerado na pasta "Fase 1"

Gerar o Access Token de produção

No painel do Mercado Pago, vá em "Suas integrações". Se não tiver uma aplicação criada, crie uma (pode usar o nome "Ki"). Copie o Access Token de produção.

Salvar num arquivo de texto simples dentro da pasta "Fase 1" — não precisa de nenhuma formatação especial

Por que isso é só seu? Esses links e o token são gerados dentro da sua conta pessoal do Mercado Pago (é ela que recebe o dinheiro das vendas), então só você tem acesso pra criar isso. Depois que estiver na pasta do Drive, eu cuido de todo o resto.

2

Automação de acesso dos clientes

Comigo (Samurai)

Ligar o Mercado Pago a um sistema de automação (Make)

Uso o Access Token da Fase 1 para configurar um fluxo que recebe o aviso de pagamento aprovado automaticamente.

Criar a conta do cliente automaticamente

Assim que o pagamento é aprovado, o sistema cria o login do cliente no site e libera o acesso à área de Configurações e Instruções.

Enviar e-mail automático com os dados de acesso

O cliente recebe usuário e senha por e-mail, em segundos, sem ninguém precisar criar a conta manualmente.

3

Teste de ponta a ponta

Os dois

Fazer uma compra de teste

Um de nós compra o Plano Basic de verdade (ou usa o simulador de testes do Mercado Pago) pra confirmar que tudo funciona: pagamento → criação de conta → e-mail → login → acesso liberado.

Revisar o conteúdo de Configurações e Instruções

Conferir se os vídeos, os links de download e as instruções estão certos e atualizados.

Se algum vídeo mudou, me manda o novo link pela pasta do Drive
